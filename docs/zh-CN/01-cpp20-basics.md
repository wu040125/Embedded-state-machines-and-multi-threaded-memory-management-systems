# 01 现代 C++20 基础

## RAII 不是“智能指针的别名”

RAII 的含义是资源获取与对象生命周期绑定。对象构造成功后资源可用，对象析构时资源一定释放。

本项目有三类典型资源：

- `FixedObjectPool::Handle` 析构时归还池块。
- `UniqueFd` 析构时调用 `close()`。
- `std::jthread` 析构或显式 `join()` 时结束线程所有权。

如果函数有多个提前返回，手写清理很容易遗漏；RAII 让每条返回路径执行同一析构逻辑。

## 移动语义表达唯一所有权

池句柄禁止复制，只允许移动：

```cpp
auto event = pool.try_create(...);
queue.wait_push(std::move(event), timeout);
```

移动后，原句柄为空，队列成为事件块的新所有者。控制线程取出句柄后成为最后一个所有者。句柄离开作用域时内存块自动归还。

思考：如果句柄允许复制，两个副本析构时会发生什么？答案是重复释放，因此编译期禁止复制比运行时补救更可靠。

## `std::jthread` 和 `std::stop_token`

`std::thread` 析构时仍可连接会调用 `std::terminate()`。`std::jthread` 提供自动连接和协作式停止令牌。

项目不使用强制杀线程。停止流程是：

1. 发布安全停机事件。
2. 请求采集和监控线程停止。
3. 唤醒周期等待。
4. 关闭事件队列。
5. 控制线程排空已有事件后退出。
6. 逐个 `join()`。

## `std::span` 与非拥有视图

I²C 接口接收 `std::span<std::byte>`。`span` 不分配内存，也不拥有数据，只表示一段连续区域。

调用者负责保证区域在函数使用期间有效。相比裸指针加长度，`span` 将地址和长度绑定在一个类型中，并支持数组直接转换。

## `std::byte`

UART 和 I²C 数据不是字符文本，因此使用 `std::byte` 表达“原始字节”。需要数值时显式调用 `std::to_integer`，避免把二进制缓冲区误当字符串。

## `std::from_chars`

命令解析使用 `std::from_chars`，原因是：

- 不依赖 locale。
- 不抛异常。
- 能检查是否消费了完整输入。
- 调用者可以明确处理范围和格式错误。

仅仅调用 `std::stod` 而不检查剩余字符，可能把 `105abc` 当成有效数字前缀。

## 模板与编译期容量

对象池和队列的容量是模板参数：

```cpp
FixedObjectPool<Event, 256>
BoundedQueue<Handle, 128>
```

这使底层存储成为对象自身的一部分，不需要运行时堆分配，也让容量约束在类型中可见。代价是不同容量属于不同类型，且过大的实例可能占用较多栈或静态存储。
